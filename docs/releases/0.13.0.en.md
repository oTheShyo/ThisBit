One change only: the old name is gone from the data, so identifiers match the product. The cost is that feedback exported before this release is no longer accepted directly.

- **Identifiers unified**: `$schema` in feedback and projects becomes `urn:thisbit:*`, and `tool.name` accepts `Thisbit` alone. The compatibility branches are gone, so an old identifier is reported as an unsupported version.
- **What it affects**: feedback JSON exported before the rename, and project files under the old extension. Open and re-export them with 0.12.1 first, then upgrade.
- **Everything else holds**: annotations, movement, long screenshots, OCR, the CLI and the skill work as before; installing and updating are unchanged.

Packages include the Windows installer and portable ZIP, universal macOS DMG, Linux AppImage, offline Web and Web Agent editions. Install or extract the complete package, keeping its runtime libraries and plugins.
